# AWS Cloud Data Migration & Validation Platform

An end-to-end serverless data migration project using Python, SQL,
Amazon S3, AWS Lambda, Step Functions, AWS Glue, and Amazon Athena.

## Objectives

- Ingest synthetic customer and account CSV files.
- Validate records against schema and business rules.
- Transform valid records into a standardized target format.
- Isolate invalid records with actionable error reasons.
- Reconcile source and target data using SQL.
- Monitor processing through Amazon CloudWatch.
- Deploy infrastructure using AWS SAM and CloudFormation.

## Data policy

All datasets are synthetic. No real customer or financial data is used.
